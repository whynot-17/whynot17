# Frozen terminology ledger

| Canonical term | Required interpretation |
|---|---|
| colorectal cancer (CRC) | Use CRC after first definition. |
| Comparative Toxicogenomics Database (CTD) | Source of human chemical–gene interactions; not direct binding targets. |
| chemical-interacting gene set | Preferred over “target set.” |
| outcome firewall | CRC outcome statistics unavailable to 267→87 actionability filtering. |
| chemical–biomarker mapping | Audit unit before collapse to unique biomarker tests. |
| unique NHANES biomarker test | Multiplicity/statistical unit; 15 tests. |
| mono(carboxy-isooctyl) phthalate (MCOP; URXCOP) | Urinary biomarker for a DINP-related exposure axis; not a significant direct CTD molecular hit. |
| monoisononyl phthalate (MiNP) | Phase 1 molecular nominee; distinct from MCOP; direct detectability 40.7% in the frozen v2 audit. |
| diisononyl phthalate (DINP) | Parent/exposure-axis chemistry; not interchangeable with MCOP or MiNP. |
| prevalent CRC | Cross-sectional current/previous CRC outcome; not incident risk. |
| complex-survey logistic regression | NHANES inference using analyte weights, strata and PSUs. |
| leave-one-cycle-out (LOCO) | Overlapping pooled re-estimates; not independent replications. |
| Robust Tier A | Prespecified robustness category; MCOP is the sole axis meeting it. |
| PPAR/nuclear-receptor (PPAR/NR) core | PPARA, PPARD, PPARG, NR1I2, NR1I3, NR1H2 and NR1H3. |
| tumor-derived epithelium | Use unless malignant annotation is directly supported. |
| paired donor | Independent inferential unit in the single-cell analysis. |
| disease-state convergence | Allowed description for CRC epithelial PPAR/NR results. |
| causal bridge | Prohibited for DINP/MCOP→PPAR/NR→CRC; this link remains untested. |
