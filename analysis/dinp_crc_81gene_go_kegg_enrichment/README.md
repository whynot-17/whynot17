# 81-gene DINP–CRC GO and KEGG enrichment

This analysis performs over-representation analysis (ORA) on the frozen 81-gene DINP–CRC intersection generated by `dinp_crc_multi_database_target_convergence`.

- Primary custom background: the union of all frozen DINP exposure genes and all frozen CRC disease-union genes (15,890 unique symbols in this release).
- Sensitivity background: the frozen CRC disease-gene union alone.
- Annotation sources: GO:BP, GO:MF, GO:CC, and KEGG through g:Profiler.
- Query and background identifiers: human gene symbols.
- Multiple testing: BH-FDR, recomputed using the complete term-family sizes reported by g:Profiler metadata.

Run:

```powershell
& C:\Users\21634\anaconda3\python.exe .\run_dinp_crc_81gene_go_kegg_enrichment.py
```

Outputs include source-separated GO/KEGG tables, combined tables, raw API JSON responses, input/background gene lists, a provenance manifest, and `summary.md`.

The result is an association-level functional annotation analysis. It does not establish chemical causality or regulatory direction.
