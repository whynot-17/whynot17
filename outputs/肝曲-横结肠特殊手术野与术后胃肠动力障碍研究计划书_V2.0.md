# 肝曲—横结肠特殊手术野与术后胃肠动力障碍研究计划书

## 一、项目名称

肝曲—横结肠特殊手术野与术后胃肠动力障碍的解剖基础、生物学脆弱性及临床意义研究

## 二、研究背景与科学问题

术后胃肠动力障碍是结肠手术后常见且具有临床影响的并发症，主要包括术后肠梗阻（POI/PPOI）以及胃排空延迟（DGE）。既往研究通常以右半结肠切除、左半结肠切除或扩大切除进行比较，但现有临床线索提示，风险可能并非均匀分布于整个右半结肠，而是集中于肝曲—横结肠及其毗邻结构所构成的连续手术区域。

该区域涉及肝曲、横结肠、横结肠系膜、middle colic vascular territory、胃结肠韧带及相关血管、淋巴和周围组织。进入或扩大处理这一手术野，可能伴随更广泛的组织牵拉、系膜处理、血管清扫及胃结肠结构改变，并由此影响术后胃肠动力调控。

本项目的核心科学问题是：

> 肝曲—横结肠是否构成结肠手术后胃肠动力障碍的特殊高风险解剖区域？如果存在，该区域的正常生物学特征是否构成可被手术扰动的动力调控脆弱性？

## 三、研究假说

本项目提出“肝曲—横结肠手术野效应”假说：进入或扩大处理肝曲—横结肠相关区域，可能增加对局部神经、免疫、间质、肌层、血管周围结构、细胞外基质及胃结肠机械联系的扰动，从而增加 POI/PPOI 和 DGE 的发生风险。

本项目不预先限定具体机制，也不将迷走神经作为必然解释。候选机制包括：

- ENS、enteric glia、ICC、平滑肌及其相互作用；
- 巨噬细胞及神经—免疫调控；
- 胆碱能或交感神经信号；
- 机械感受与组织力学环境；
- 血管/血管周围生物学；
- 系膜、胃结肠区域的结构与细胞外基质改变。

研究遵循“先发现异常，再确定机制”的原则。

## 四、研究目标

### 目标一：建立以实际手术野为基础的临床暴露定义

将肿瘤位置与实际手术操作分开记录，建立肝曲—横结肠手术野暴露分级，并评价其与 POI/PPOI、DGE 之间的关系。

### 目标二：识别横结肠区域的正常生物学特征

利用配对的人体公共组学和空间数据，比较同一供者的升结肠、横结肠和降结肠，判断横结肠是否存在稳定、可重复且与胃肠动力相关的分子、细胞状态或空间组织特征。

### 目标三：定位潜在的动力调控机制

当发现稳定候选信号后，进一步确定其来源细胞、空间关系、调控状态及其在 ENS、glia、ICC、平滑肌、免疫和血管相关系统中的功能联系。

### 目标四：进行解剖连续性和临床相关性验证

在精确解剖取材的人体组织中验证候选信号，并在临床队列中检验手术野暴露是否独立增加 POI/PPOI 或 DGE 风险。

## 五、研究内容与技术路线

### 研究内容一：临床证据整合与手术野分级

现有研究线索提示，普通右半结肠切除与左半结肠切除的差异可能并不稳定，而涉及横结肠或扩大切除的手术，其胃肠功能恢复可能更差。近端横结肠及胃结肠相关扩大手术还提示 DGE 风险，说明结肠手术可能通过区域性结构或神经—免疫联系影响胃动力。

后续临床研究应记录：肿瘤精确位置、肝曲及脾曲游离、横结肠切除范围、横结肠系膜处理、middle colic vessels 处理、相关淋巴结清扫、胃结肠韧带处理、CME/D3、手术方式、手术时间、阿片使用及 ERAS 执行情况。

拟建立四级手术野暴露：

| 分级 | 定义 |
|---|---|
| 0级 | 未明显进入横结肠相关区域 |
| 1级 | 肝曲或近端横结肠操作 |
| 2级 | 明显横结肠切除或横结肠系膜处理 |
| 3级 | 涉及 middle colic root、相关淋巴区域、胃结肠韧带、扩大结肠切除或脾曲游离等 |

主要结局包括 POI、PPOI、DGE、胃管再置入、首次排气、首次排便、固体饮食耐受和住院时间。重点检验手术野暴露与结局之间是否存在独立关联及剂量—反应关系。

### 研究内容二：HuBMAP 配对队列的横结肠特异性发现

主发现数据集为 HuBMAP 队列 HBM692.JRZB.356，包含多个供者的升结肠、横结肠和降结肠样本，并具有单核转录组、单核染色质可及性和 CODEX 空间数据。该队列的核心优势是供者内配对比较。

首先保留已完成的细胞组成分析结果：粗粒度上皮、免疫和基质细胞比例未显示稳定的横结肠特异性富集。这一阴性结果说明，横结肠的潜在特殊性不一定来自某一大类细胞数量增加，但不能排除同类细胞在不同区域具有不同功能状态。

下一步重点开展供者水平的表达状态分析。横结肠特异性信号必须同时满足：

- 横结肠相对升结肠方向一致；
- 横结肠相对降结肠方向一致；
- 在供者之间具有较好的重复性；
- 具有可解释的功能模块或动力学联系。

重点评价效应量、假发现率、供者一致性和跨比较方向的一致性，而不以单个显著性结果作为唯一依据。整体组织分析发现信号后，进一步在上皮、成纤维细胞、内皮细胞、巨噬细胞、平滑肌、神经胶质、神经元及其他覆盖充分的细胞群中进行细胞类型分辨分析。

### 研究内容三：空间组织、调控状态与独立验证

如果转录差异较弱，将重点转向 CODEX 空间数据，分析横结肠是否存在不同于升结肠和降结肠的细胞邻域、组织单元、肌层相关结构、免疫—基质邻域、血管/血管周围组织及其他区域性共定位关系。

单核染色质可及性数据主要用于验证候选信号的调控基础。当转录组发现某一细胞群或功能程序时，进一步判断对应的调控区域和转录因子基序是否呈同方向改变。转录与调控层的一致性将提高候选机制的可信度，但不单独构成因果证据。

独立数据的功能定位如下：

- GSE185224：验证上皮细胞中的区域性表达信号；
- HGCA：当主队列出现免疫或巨噬细胞信号时，用于独立验证；
- GSE156905 及人类 ENS 图谱：定位神经元、肠神经胶质、ICC、平滑肌和巨噬细胞等动力相关细胞中的候选机制，不作为正常横结肠特异性的主要发现证据。

### 研究内容四：人体组织的精确解剖验证

公共数据通常难以覆盖肝曲、近端横结肠、中段横结肠、远端横结肠和脾曲的连续取样。因此，若公共数据发现候选轴，将在自有组织中进行连续解剖验证：

升结肠 → 肝曲 → 近端横结肠 → 中段横结肠 → 远端横结肠 → 脾曲 → 降结肠。

验证重点不是重新开展无假说的全探索，而是判断候选信号是否沿解剖区域呈现稳定模式，并评估其与神经、免疫、肌层、血管和系膜结构的关系。

### 研究内容五：临床相关性与机制研究

当候选生物学脆弱性得到组织和公共数据支持后，进一步研究其是否可能被手术切除、牵拉、血管处理、淋巴清扫或胃结肠结构改变所扰动，并与 POI/PPOI 和 DGE 的临床表型建立联系。

机制研究的优先方向由数据决定，可包括 enteric glia—macrophage、ICC—平滑肌、自主神经/胆碱能、交感/肾上腺素能、血管周围、机械感受或系膜细胞外基质等轴线。

## 六、研究判定标准与停止规则

### 阳性标准

候选信号至少应具备以下特征中的主要部分：横结肠区域特异、供者间一致、跨数据集重复、具有明确细胞或空间来源，并与胃肠动力具有合理的生物学联系。真正进入实验的目标应是一个稳定、可解释且可验证的机制轴，而不是数量众多的差异基因。

### 分阶段决策

- 若发现稳定的分子程序、细胞状态、空间邻域或调控状态，并得到跨数据支持，则进入组织和机制验证。
- 若仅发现中等强度但供者一致的信号，则先进行独立数据验证，复现后再深入。
- 若转录、空间和调控层均未发现稳定的横结肠特异性信号，则停止“正常横结肠先天分子特殊性”方向，不再强行寻找迷走神经或其他预设解释，转向手术损伤、机械扰动、炎症反应和围术期因素机制。

## 七、项目创新点

1. 将研究对象从“右半结肠切除”重新聚焦为可解剖定义的肝曲—横结肠手术野。
2. 将 POI/PPOI 与 DGE 分开分析，关注结肠手术后胃排空障碍这一具有机制价值的表型。
3. 采用供者内配对设计，区分真正的横结肠特异性与单纯的近端—远端梯度。
4. 将细胞状态、空间组织和调控状态结合起来，避免仅凭细胞比例或单个差异基因推断机制。
5. 建立“公共数据发现—精确解剖验证—临床手术野验证”的递进式研究框架。

## 八、预期结果与可能贡献

本项目预期明确以下问题：横结肠是否具有可重复的动力相关生物学特征；该特征由哪些细胞、空间结构或调控程序构成；其是否可能被特定手术操作扰动；以及实际手术野暴露是否比传统的手术名称或肿瘤侧别更能解释 POI/PPOI 和 DGE 风险。

若研究闭环成立，最终模型为：

> 肝曲—横结肠手术野暴露 → 区域性生物学脆弱性 X 被切除、牵拉或清扫扰动 → 局部或远隔胃肠动力调控异常 → POI/PPOI 和/或 DGE。

若生物学特异性未被证实，项目仍可形成明确结论：术后动力障碍更可能主要源于手术造成的机械、神经、血管或炎症损伤，而非正常横结肠本身的先天分子差异。

## 九、当前研究阶段

目前已完成：

- 临床问题从“右半结肠效应”收缩至“肝曲—横结肠手术野效应”；
- 公共数据集筛选与研究定位；
- HuBMAP 队列的初步细胞组成分析。

当前首要研究任务是完成 HuBMAP 单核转录组的供者水平表达状态分析，比较横结肠与升结肠、降结肠的差异，并综合效应量、统计可靠性、供者一致性和功能解释。后续研究方向依据预设判定标准决定：有稳定阳性则追踪候选机制；信号较弱则优先进行空间和独立数据验证；多层数据均阴性则转向手术损伤机制。

## 十、研究边界

本计划书描述的是科研问题、研究假说、研究对象、证据链和判定标准，不预设具体执行软件、分析平台或单一技术路线。所有机制性结论均需以实际数据、独立验证和适当的因果研究为依据，不将相关性结果直接表述为因果关系。
