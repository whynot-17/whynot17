# Phase 0B：全文级 Surgical-field Reconstruction

## 目标

本阶段将 Phase 0 的术式分类进一步拆解为实际手术野。每一个解剖结构都必须有原文或全文操作描述支持，不能根据“右半结肠切除”或“扩大右半结肠切除”的名称自动推定。

结构化结果见 [`phase0b_surgical_field_reconstruction.csv`](phase0b_surgical_field_reconstruction.csv)。

## 编码规则

| 代码 | 含义 |
|---|---|
| 1 | 文献明确报告涉及该结构 |
| 0 | 文献明确报告未涉及该结构 |
| NR | 文献未报告，不能推断 |
| mixed | 队列内不同患者或不同术式不一致，需要分层 |

`NR` 不是“没有处理”，而是“当前证据不能判断”。这是本阶段最重要的防止过度解释规则。

## 本轮全文级提取结果

### E003：REC 研究

REC 的图示/文字明确显示其切除范围跨越右侧结肠、横结肠并延伸至近端降结肠，因此可以确认“切除范围扩大且跨越横结肠”。但文献当前可核对内容没有充分拆出肝曲是否单独游离、横结肠系膜处理深度、middle colic root 的处理方式以及胃结肠韧带/GCLN 是否处理。

因此，E003 支持“扩大切除范围与 PPOI 风险相关”，但不能进一步定位到某一个手术结构。其结果表中 REC 组的 NGT 使用为 18.8%，RC 为 7.2%，LC 为 4.1%；排气、排便、固体饮食和住院时间也显示 REC 恢复较慢。该研究仍然是“范围效应”证据，而不是“结构效应”证据。

### E004：横结肠癌与 DGE

该研究明确把横结肠癌手术、胃结肠韧带和胃结肠韧带/幽门下淋巴结区域联系起来，并报告 DGE 信号。它是当前矩阵中最直接的“胃结肠相关手术野—DGE”证据之一。

但目前仍缺少完整全文提取：病例总数、DGE 的操作性定义、机械性梗阻排除方式、GCLN 清扫的具体范围以及多因素调整变量。因此该证据可以提升候选区域的优先级，但还不能单独推动 Gate 1 通过。

### E005：近端横结肠、GCLN 与胃后结构

这项随机研究的手术背景明确为近端横结肠癌、右半结肠切除和扩大淋巴结清扫，且全文检索内容明确提及 GCLN 清扫、胃结肠韧带切除以及胃在幽门下/胃后区域的术后位置变化。常规组 DGE 为 38.7%，胃固定组为 12.1%。

这项研究的价值在于，它不仅观察到 DGE，还提出了一个具体的局部结构解释：胃结肠区域处理后，胃窦/胃后关系改变，可能影响胃排空。其局限也同样明确：随机的是胃固定干预，而不是是否进入该手术野，所以它支持“区域内结构机制的可行性”，不等于证明“区域暴露本身具有因果效应”。

### E006：Aden 研究

全文明确记录了右半和扩大右半结肠切除，也记录了横结肠肿瘤位置、吻合方式、手术时间和阿片使用。但没有将肝曲、横结肠系膜、middle colic root、胃结肠韧带或 GCLN 清扫逐项编码。

横结肠肿瘤位置在单因素分析中有信号，但多因素模型主要保留手术时间和术后阿片因素。这是一个重要的反证：肿瘤位置不能替代实际手术野，且操作复杂度可能是中介因素或混杂因素。

### E007：吻合技术研究

该研究的全文重点是腹腔内与腹腔外吻合、系膜张力和肠管动员，而不是肝曲—横结肠具体结构。其 POI 差异说明技术因素本身足以改变术后恢复，因此 Phase 0B 必须把吻合方式和肠管动员作为独立变量，而不能将所有恢复差异归因于区域暴露。

### E001、E002、E008、E009

这些研究可以支持右侧/左侧 POI 差异或提供一般性混杂因素背景，但不能重建目标手术野。它们在结构矩阵中大部分标为 `NR`，这不是信息缺失的瑕疵，而是本项目当前最重要的证据缺口。

## Gate 1B 判定

### 仍未通过：尚未完成结构级定位

当前 9 项证据可以分成三类：

1. **侧别/范围证据**：E001、E002、E003、E008，支持右侧或扩大切除后 POI/PPOI 增加。
2. **胃结肠区域 DGE 证据**：E004、E005，支持横结肠近端及胃结肠/GCLN 相关区域值得重点定位。
3. **混杂与反证证据**：E006、E007、E009，说明肿瘤位置、吻合方式、手术时间、阿片和患者因素可能独立影响 POI。

目前还没有足够的跨研究对照，能够同时满足以下模式：

> 同类手术中，仅增加某个明确手术结构的处理，就稳定增加 POI/DGE；或不同术式中，只要共同进入该结构区域，就出现相同表型。

因此当前最准确的结论是：

> **区域效应仍是有临床支持的候选解释，但尚未被结构级证据定位。**

## 下一轮 Phase 0B 工作

下一轮优先补充两类研究，而不是进入公共组学：

1. 直接比较横结肠段切除、扩大右半切除和扩大左半切除，并报告 POI/PPOI 或 DGE 的研究；
2. 明确报告 GCLN、胃结肠韧带、middle colic root、横结肠系膜或幽门下区域处理，并同时报告胃肠动力结局的研究。

对每篇全文继续提取：

- 肿瘤精确位置；
- 切除的肠段；
- 肝曲/脾曲游离；
- 横结肠系膜与 middle colic root 的处理层级；
- 胃结肠韧带、GCLN、infrapyloric field；
- 吻合方式、肠管动员与手术时间；
- POI/PPOI 与 DGE 的独立定义、分母和时间窗；
- 多因素模型中的手术野变量与主要混杂因素。

只有当这些资料能形成“结构进入—表型重复”的跨研究模式，Gate 1 才能通过，随后才进入 Dataset Discovery。

## 当前结论

Phase 0B 没有把“右侧效应”强行改写成“横结肠效应”，反而确认了从侧别到手术结构之间仍存在一个必须填补的证据层。当前最高价值的工作仍是继续全文级手术野重建，而不是提前选择组学数据或机制通路。
