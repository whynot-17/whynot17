# Phase 0：Clinical Evidence Reconstruction

## 研究问题

本阶段不预设 HuBMAP、GEO、迷走神经或任何候选通路，只检验：

> 术后 POI/PPOI 或 DGE 的风险，是否更接近于“实际手术野暴露”，而不是简单的右侧/左侧或肿瘤位置分类？

## 本轮工作范围

本轮完成了针对右/左结肠切除、扩大右半结肠切除、横结肠癌手术、胃结肠韧带/相关淋巴结清扫及术后胃排空延迟的第一轮 PubMed 证据检索。证据表见 [`phase0_clinical_evidence_matrix.csv`](phase0_clinical_evidence_matrix.csv)。

当前表格是“证据重建工作表”，不是已经完成的系统综述。所有未能从摘要或可核对全文中确认的手术结构、分母、诊断标准和调整变量均保留为缺失或待全文提取，不作推断。

## 初步证据分层

### 1. 右侧/扩大切除与 POI/PPOI

右侧结肠切除相对于左侧切除的 POI/PPOI 增加，在多个观察性队列和一项系统综述/荟萃分析中重复出现。Seo 等的荟萃分析纳入 29,068 例结肠切除，报告右侧切除后 PPOI 的优势比为 1.78，但同时指出 PPOI 定义不一致、其他胃肠恢复结局资料不足。[E001](https://pubmed.ncbi.nlm.nih.gov/34714601/)

Garfinkle 等使用倾向平衡后的 NSQIP 队列，右侧切除 pPOI 为 11.5%，左侧为 8.8%，调整后右侧切除仍与较高 pPOI 几率相关。[E002](https://pubmed.ncbi.nlm.nih.gov/31828500/)

Parnasa 等进一步比较右半、左半和扩大右半结肠切除，扩大右半切除组的排气、固体饮食耐受、胃管使用和住院时间均较差，调整后扩大右半切除仍被识别为 PPOI 风险因素。[E003](https://pubmed.ncbi.nlm.nih.gov/40461834/)

这组证据支持“切除范围/手术复杂度存在梯度”，但尚未回答：风险究竟来自横结肠、近端降结肠、系膜处理、血管清扫、吻合方式，还是手术时间及其他伴随因素。

### 2. 横结肠相关手术与 DGE

目前最直接的 DGE 证据集中在近端横结肠及胃结肠相关手术。Chi 和 Huang 的临床报告指出，横结肠癌手术后 DGE 发生率高于其余结肠癌手术，并报告胃结肠韧带淋巴结清扫组高于未清扫组；但该文为中文文章，摘要未提供足够的队列、诊断和调整细节，因此需要全文提取后才能作为高等级证据使用。[E004](https://pubmed.ncbi.nlm.nih.gov/35754213/)

Popescu 等开展了近端横结肠癌右半结肠切除加扩大淋巴清扫背景下的随机研究，比较胃固定与常规处理，DGE 在常规组为 38.7%，胃固定组为 12.1%。这说明 DGE 是一个可观察且可能与局部胃后/胃结肠结构改变有关的表型，但该研究并未随机比较“进入手术野”与“不进入手术野”，因此不能单独证明区域暴露的因果效应。[E005](https://pubmed.ncbi.nlm.nih.gov/37746998/)

### 3. 反证与混杂因素

Aden 等在高 ERAS 依从性的右半/扩大右半结肠切除队列中，横结肠肿瘤位置在单因素分析中与 POI 相关，但在报告的多因素模型中，独立预测因素主要是手术时间和术后阿片使用。这提示“肿瘤位置”不能直接替代“实际手术野”，也提示操作复杂度和围术期因素必须进入 Phase 0 的混杂因素框架。[E006](https://pmc.ncbi.nlm.nih.gov/articles/PMC11390276/)

吻合方式、既往腹部手术、性别、慢性肺病、造口等因素也可能影响 POI。相关研究不能用来支持区域效应，但必须作为负对照或调整变量保留。[E007](https://pubmed.ncbi.nlm.nih.gov/36910563/)、[E008](https://onlinelibrary.wiley.com/doi/abs/10.1111/ases.13227)、[E009](https://pubmed.ncbi.nlm.nih.gov/22083434/)

## Gate 1 当前判定

### 判定：有初步支持，但尚未通过

理由如下：

1. 右侧与扩大右侧切除后的 POI/PPOI 增加具有重复性。
2. 近端横结肠/胃结肠相关手术后的 DGE 信号具有直接临床依据。
3. 目前缺乏足够研究将手术暴露拆解到肝曲、近端横结肠、横结肠系膜、middle colic root、胃结肠韧带和相关淋巴清扫等结构。
4. 现有研究中手术时间、吻合方式、阿片使用、既往手术和患者特征等混杂因素尚未被统一处理。

因此，当前不能写成“肝曲—横结肠手术野已经被证明是高风险区域”。更准确的表述是：

> 现有证据提示右侧/扩大切除及近端横结肠相关手术可能存在 POI/PPOI 或 DGE 风险信号，但现有研究尚未完成以实际手术野为单位的因果定位。

## 下一步工作

下一轮不进入组学，而是继续完成全文级证据重建：

1. 为每篇研究补齐实际切除范围、游离范围、血管处理、系膜处理和胃结肠区域操作。
2. 统一 POI、PPOI、DGE 的定义、诊断时间窗和排除机械性梗阻的条件。
3. 将每个手术拆解为手术野暴露矩阵：肝曲、近端横结肠、中段横结肠、远端横结肠、脾曲、横结肠系膜、middle colic root、胃结肠韧带、GCLN/infrapyloric field 等。
4. 明确哪些研究支持、反对或无法判断区域效应。
5. 只有当矩阵显示区域效应具有跨研究重复性后，才进入 Dataset Discovery，寻找能够覆盖相应解剖位置的正常人体数据。

## 当前证据边界

- 不能把右侧切除等同于肝曲—横结肠暴露。
- 不能把横结肠肿瘤位置等同于实际手术野。
- 不能把 DGE 与 POI/PPOI 合并成一个终点。
- 不能把观察性关联表述为因果关系。
- 不能在证据矩阵完成前提前选择某个组学数据库或某条机制通路。
