# Legacy CRC cohort clinical-label audit

This folder contains a metadata-only feasibility audit for GSE39582, GSE28702 and GSE122246. No expression matrices were downloaded or analyzed. Read [the Chinese audit](cohort_label_audit_zh.md) and [the cohort summary CSV](cohort_label_audit.csv).

The audit evaluates sample/event counts, treatment and follow-up labels, prior published use, covariate availability and whether each cohort can support the planned patient-level questions. It does not report differential expression, pathway enrichment, classifier fitting, or direct MRD/ctDNA evidence.

Audit date: 2026-10-10.
